### Engineering Focus

- **Inference & Model Optimization:** Accelerating deep learning workloads for edge and cloud deployment using **TensorRT, ONNX, CUDA, vLLM, and llama.cpp** (quantization & GPTQ).
- **LLM Post-Training & Alignment:** Fine-tuning foundation models via **LoRA, PEFT, and RLHF** for domain-specific reasoning, evaluation, and compliance.
- **Agentic & RAG Systems:** Designing multi-agent orchestration, hybrid retrieval pipelines (**LangChain, LlamaIndex, FAISS, ChromaDB**), and automated auditing suites.
- **Computer Vision, Audio & Full-Stack AI:** Building real-time mobile sound classification, privacy-preserving detection models, generative media tools, and scalable web/backend interfaces.
