### Engineering Focus

- **Inference & Model Optimization:** Accelerating deep learning workloads for edge and cloud deployment using **TensorRT, ONNX, CUDA, vLLM, and llama.cpp** (GPTQ / quantization).
- **LLM Post-Training & Alignment:** Fine-tuning foundation models (Llama, GPT, Falcon, BERT) via **LoRA, PEFT, and RLHF** for domain-specific reasoning and safety compliance.
- **Agentic & RAG Systems:** Designing multi-agent orchestration, hybrid retrieval pipelines (**LangChain, LlamaIndex, FAISS**), and automated LLM evaluation frameworks.
- **Computer Vision & Audio:** Building real-time mobile sound classification, privacy-preserving object detection, and generative media pipelines.
